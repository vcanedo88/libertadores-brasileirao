# Quem vai à Libertadores? Simulação 2026

Painel do Canal do Canedo com as vagas na Libertadores 2027 pelo Brasileirão 2026: G6, G7, G8 ou G9, a chance de cada clube (fase de grupos e pré), o índice da reta final e a autocrítica do modelo.

50 mil cenários com o modelo do canal (índice v11), atualizados depois de cada dia de jogos. Dados de xG: FotMob (Opta). Tabela: CBF.
